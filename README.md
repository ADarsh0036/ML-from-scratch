# Scratch_Implementations

In this repository you will find the scratch implementations of:

## 1) Classical ML Models (NumPy Implementations)
- **a) Naive Bayes Classifier**
- **b) Logistic Regressor**
- **c) Linear Regressor**
- **d) Gaussian Mixture Model + EM (GMM + EM)**

## 2) Deep Learning (NumPy Implementations)
- **a) Dense Neural Network Architecture with BackPropagation using Optimization Methods like:**
  - a1) SGD
  - a2) SGD + Momentum
  - a3) Adam

## 3) Advanced Deep Learning Models
- **a) Vector Quantized Variational Auto Encoder (VQ-VAE)**
  > Follows direct implementation from Paper: *Neural Discrete Representation Learning*

- **b) Deep Convolutional Generative Adversarial Networks (DCGAN)**
  > Follows direct implementation from Paper: *Unsupervised Representation Learning with Deep Convolutional Generative Adversarial Networks*

- **c) Generative Adversarial Networks with Cycle Consistency (CycleGAN)**
  > Follows direct implementation from Paper: *Unpaired Image-to-Image Translation using Cycle-Consistent Adversarial Networks*
